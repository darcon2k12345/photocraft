Patronus Photo portable mode

While this file sits next to patronusphoto.exe, Patronus Photo keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the PatronusPhotoData folder beside it, and writes
nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Patronus Photo with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\Patronus Photo for settings
and %LOCALAPPDATA%\Patronus Photo\Recovery for crash-recovery autosaves. If PatronusPhotoData can't be
written (for example on a read-only drive), Patronus Photo says so and uses those folders instead.
